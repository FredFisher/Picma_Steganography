# Picma_Steganography
Digitale Kommunikation ist seit jeher Angriffen ausgesetzt, sei es in Bezug auf die Geheimhaltung oder die Integrität von Informationen.  

Trotz der schier endlosen Kreativität von Entwicklern und Forschern ist es nie gewiss, ob es nicht bald für die beste Verschlüsselung einen neuen “Workaround” gibt. 

 

Deswegen will ich hier eine weiter Stufe der Sicherheit einbringen: Picma. 

Mithilfe des Prinzips “Security through Obscurity” und dem Programm Picma kann selbst eine Abgefangene Nachricht ohne die nötige Software nicht richtig interpretiert werden.  

Falls die Informationen von einem Angreifer abgefangen werden, sieht dieser nur eine unscheinbare Bilddatei.
